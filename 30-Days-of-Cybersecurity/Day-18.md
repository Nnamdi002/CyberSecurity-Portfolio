## 1. Operating Systems: Introduction

This room helped me understand the role of an operating system in managing a computer's hardware, applications and resources.

### Key Concepts

**Operating System:** Software that manages hardware resources and allows applications to function.

**Kernel Space:** A privileged environment where the operating system manages critical hardware and system resources.

**User Space:** An environment where regular applications operate with restricted permissions.

**GUI and CLI:** Two different ways users interact with operating systems.

The room also introduced user privileges, process management, memory management and file systems.

### What I Learned

An operating system does more than provide a desktop interface. It controls how applications interact with hardware and helps enforce security boundaries.

## 2. Windows Basics

This room focused on navigating and managing a Windows operating system.

### Key Concepts

I explored Windows features including:

- Windows Settings and Control Panel
- Application installation and removal
- Task Manager and running processes
- User accounts and system information
- Windows Security and antivirus protection
- Windows Defender Firewall

### Connection to Cybersecurity

Understanding Windows system tools is important because they help users and security professionals inspect system activity, manage applications and identify potential security concerns.

I also learned how built-in security tools contribute to protecting Windows computers against malware and unauthorised network access.

## 3. Security Awareness

The third room focused on understanding everyday cybersecurity risks and the importance of protecting personal information.

### Key Concepts

The topics covered included:

- The importance of cybersecurity awareness
- Different types of threat actors
- The potential impact of cyberattacks
- Basic account security practices
- Protecting personal information online

### What I Learned

Security awareness is an important part of cybersecurity because individuals can become targets of attacks.

Understanding common threats and developing good security habits can reduce the likelihood of falling victim to cybercrime.
