| Security Feature | Purpose | Observed Status |
|---|---|---|

| Firewall & Network Protection | Helps control network traffic and unauthorised connections | No action needed |
| App & Browser Control | Helps protect against unsafe applications and websites | No action needed |

The results indicated that Windows Security had not identified any issues requiring immediate attention in these sections.

## Connection to Cybersecurity

This exercise helped me connect the **CIA Triad** to practical security measures:

- **Confidentiality:** Security controls help prevent unauthorised access to sensitive information.
- **Integrity:** Malware protection helps prevent malicious modifications to files and systems.
- **Availability:** Security measures help reduce threats that could disrupt access to systems and data.

I also gained a better understanding of defensive cybersecurity, which focuses on protecting systems, detecting threats and responding to security incidents.

## Key Takeaway

Cybersecurity involves more than identifying threats. It also requires understanding how different security controls work together to protect devices, networks and information.
