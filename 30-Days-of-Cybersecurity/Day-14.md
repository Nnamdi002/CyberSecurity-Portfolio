## What I Learned

### 1. Windows Desktop and Interface

I explored the Windows desktop, including the Start Menu, Taskbar, Search Box and Notification Area. These features make it easier to navigate the operating system and manage applications.

### 2. Windows File System (NTFS)

I learned that NTFS (New Technology File System) is a file system used by Windows to organise and manage files.

NTFS supports features such as access permissions, encryption and compression.

### 3. Windows System32 Folder

The `C:\Windows\System32` folder contains important Windows system files and utilities.

This helped me understand why protecting critical system files against unauthorised changes is important.

### 4. User Accounts and Permissions

I learned the difference between administrator and standard user accounts.

Administrators have elevated privileges, while standard users have restricted permissions.

This relates to the **principle of least privilege**, which means giving users only the access necessary to perform their tasks.

### 5. User Account Control (UAC)

UAC helps protect Windows by prompting for approval or administrator credentials when certain actions require elevated privileges.

### 6. Windows Settings and Task Manager

I explored the purpose of Windows Settings, Control Panel and Task Manager, including how these utilities help users manage system configurations, applications and running processes.

## Connection to Cybersecurity

This learning activity helped me understand that operating system security starts with controlling access to files, applications and system resources.

Windows features such as NTFS permissions, user account restrictions and UAC can help reduce the risk of unauthorised access or unwanted system changes.

## My Key Takeaway

Before learning how to defend computer systems against cyber threats, I need to understand how those systems work.

This activity helped me look beyond the familiar Windows desktop and appreciate the importance of operating system fundamentals in cybersecurity.
