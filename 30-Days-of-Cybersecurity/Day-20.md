## 1. What Is a Computer Network?

A computer network is a collection of connected devices that communicate and share information or resources.

Examples include home Wi-Fi networks, office networks and the internet.

## 2. Types of Networks

I learned about four common types of networks.

| Network | Meaning | Example |
|---|---|---|
| PAN | Personal Area Network | Bluetooth connection between a phone and smartwatch |
| LAN | Local Area Network | Home or office network |
| MAN | Metropolitan Area Network | Network covering a city or large metropolitan area |
| WAN | Wide Area Network | The internet |

These network types differ mainly in their geographical coverage and purpose.

## 3. Network Topologies

Network topology describes how devices are connected within a network.

The class introduced several topologies:

- **Bus:** Devices share a common communication backbone.
- **Star:** Devices connect through a central switch or hub.
- **Ring:** Devices are arranged in a circular connection.
- **Mesh:** Devices have multiple interconnected paths.
- **Tree:** Devices are organised in a hierarchical structure.

I learned that network design can affect performance, reliability and fault tolerance.

## 4. Networking Devices

We explored the functions of common networking devices.

| Device | Function |
|---|---|
| Hub | Sends incoming data to other connected devices |
| Switch | Connects devices within a network and forwards frames using MAC addresses |
| Router | Connects different networks and routes packets using IP addresses |
| Firewall | Filters network traffic based on security rules |
| Server | Provides resources or services to connected clients |
| Endpoint | A device such as a laptop, desktop or smartphone |

## 5. MAC Addresses and IP Addresses

One important topic was understanding the difference between MAC and IP addresses.

**MAC Address (Media Access Control):**

A MAC address identifies a network interface and is used for local network communication.

It typically uses a 48-bit hexadecimal format.

**IP Address (Internet Protocol):**

An IP address is a logical network address used to identify interfaces and enable communication across IP networks.

We learned about two IP versions:

**IPv4:** Uses 32-bit addresses, such as `192.168.1.100`.

**IPv6:** Uses 128-bit addresses and provides a much larger address space.

We also discussed public and private IP addresses.

Private IP addresses are used within local networks, while public IP addresses support communication across the internet.

## 6. Understanding the OSI Model

The OSI (Open Systems Interconnection) model is a seven-layer reference framework used to understand network communication.

| Layer | Name | Main Function |
|---|---|---|
| 7 | Application | Provides network services to applications |
| 6 | Presentation | Handles data formatting and representation |
| 5 | Session | Manages communication sessions |
| 4 | Transport | Supports end-to-end data delivery |
| 3 | Network | Handles logical addressing and routing |
| 2 | Data Link | Handles local frame delivery using MAC addresses |
| 1 | Physical | Transmits bits through physical media |

The OSI model helps explain how communication occurs and provides a framework for troubleshooting network problems.

## 7. The TCP/IP Model

The TCP/IP model is a practical framework used for internet communication.

It consists of four layers:

| Layer | Examples |
|---|---|
| Application | HTTP, FTP |
| Transport | TCP, UDP |
| Internet | IP, ICMP |
| Network Access | Ethernet, Wi-Fi |

Understanding both models provides a foundation for studying network protocols and cybersecurity threats.

## 8. Encapsulation and De-encapsulation

Another interesting concept introduced during class was encapsulation.

Encapsulation involves adding protocol information to data as it moves through network layers before transmission.

The process can be represented as:

**Data → Segment → Packet → Frame → Bits**

At the receiving device, de-encapsulation removes the relevant protocol information as the data moves up the layers.

The parcel delivery analogy used during class helped me understand how each layer prepares data for delivery to its intended destination.

## 9. Connection to Cybersecurity

Networking knowledge is important in cybersecurity because it helps professionals understand how devices communicate and how network traffic can be monitored and protected.

For example:

- Firewalls help control traffic entering or leaving networks.
- IP addresses support routing and network identification.
- Switches use MAC addresses to forward frames within local networks.
- Network models help professionals understand where communication problems and security threats may occur.
