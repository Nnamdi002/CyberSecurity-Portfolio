## Overview

With no scheduled class at TS Academy today, I continued my independent learning on TryHackMe, exploring how computer components function and work together.

## What I Learned

I studied the main components of a computer and their functions:

| Component | Function |
|---|---|
| CPU | Processes instructions and performs calculations |
| RAM | Temporarily stores data needed by running programs |
| Motherboard | Connects computer components and enables communication |
| HDD/SSD | Provides long-term storage for files and applications |
| PSU | Supplies electrical power to computer components |

### Understanding the Boot Process

I also explored how a computer starts up:

1. **BIOS/UEFI:** Initialises hardware when the computer is powered on.
2. **POST:** Checks essential hardware components.
3. **Bootloader:** Helps load the operating system.

## Connection to Cybersecurity

Understanding computer hardware and the boot process provides a foundation for identifying vulnerabilities and securing computer systems.

Security threats can target different layers of a computer, including its firmware, operating system and stored data.

## Key Takeaway

Before learning how to protect a computer system, it is important to understand how its components work together.
